# Nipuna Dilshan — Portfolio

Personal portfolio website for **Nipuna Dilshan**, AI Solutions Engineer.

## Tech Stack

- **React 19**
- **Vite**
- **Tailwind CSS**
- **Lucide React**

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run local dev server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```
